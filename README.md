# fitnoss

Каталог упражнений, конструктор программ и дневник тренировок. Сайт полностью статический: живёт на GitHub Pages, без бэкенда и базы данных, работает офлайн.

**https://fitnoss.github.io**

- **880 упражнений** с фото и пошаговой техникой: дом, турник и брусья, гантели, гиря, резинки, зал. Поиск на русском и английском, фильтры по мышцам, инвентарю и уровню.
- **Программы**: дни, подходы, повторы (числом, диапазоном, на время, AMRAP), отдых, вес, заметки. Есть шаблоны.
- **Ссылка = программа.** Свой битовый формат FitPack упаковывает программу на 4 дня по 6 упражнений примерно в 65 символов. Плюс QR-код и текст для мессенджеров.
- **Режим тренировки**: отметка подходов, таймер отдыха (вибрация и звук, работает в фоне), экран не гаснет, цели подставляются из прошлой тренировки. Упражнение можно заменить на аналог для тех же мышц с доступным инвентарём; выполненные подходы сохраняются.
- **Прогресс**: история, рекорды, графики e1RM, веса и тоннажа, недельная серия.
- **Калькуляторы**: 1ПМ, раскладка блинов, ИМТ, калории.
- **PWA**: ставится на телефон, работает без интернета. Все данные хранятся в localStorage, есть экспорт и импорт бэкапа.
- **Языки**: русский и английский, новые добавляются JSON-файлом (см. [CONTRIBUTING.md](CONTRIBUTING.md)).

## Разработка

```bash
npm install
npm run dev
```

| Команда | Что делает |
|---|---|
| `npm run data` | собирает упражнения, фото, переводы → `public/` |
| `npm run new-exercise -- <slug>` | новое упражнение из шаблона ([content/README.md](content/README.md)) |
| `npm run i18n:check` | отчёт по переводам |
| `npm run videos:find` | подбор YouTube-кандидатов для ручной проверки |
| `npm test` | тесты (кодек ссылок, калькуляторы) |
| `npm run build` | сборка в `dist/` |

Стек: Vite, React, TypeScript, Tailwind CSS, shadcn/ui, Zustand, i18next, Workbox.

## Деплой

Push в `main` → GitHub Actions ([deploy.yml](.github/workflows/deploy.yml)) собирает и публикует сайт. Один раз в настройках репозитория: **Settings → Pages → Source: GitHub Actions**.

# Project instructions

## Product stage

- The project has no users yet.
- Backward compatibility is not required unless the user explicitly requests it.
- Prefer a clean current implementation when changing routes, data formats, or APIs. Do not add redirects, migrations, legacy adapters, or parallel obsolete formats solely for compatibility.
- The More tab opens settings directly. Keep calculators and About as actions at the top; data and offline remain sections of settings. Do not introduce an intermediate settings menu.

## Git preferences

- After completing work in this repository, create a commit containing your changes. Do not commit unrelated user changes.
- Do not add Co-authored-by trailers to commit messages.

# Внедрение и приёмка UX-аудита

Дата: 31 октября 2026. Основа: `UX_AUDIT.md`.

**Статус:** кодовые изменения внедрены и проверены локально. Приёмка на физическом телефоне, реальным скринридером и наблюдаемые пользовательские сессии ещё не проведены. Полное закрытие аудита пока не подтверждено.

## Решения пользователя, имеющие приоритет над предложениями аудита

- Вкладка «Ещё» сразу показывает настройки. Калькуляторы и информация о приложении доступны кнопками сверху. «Ваши данные» и «Офлайн» — группы на этой же странице. Промежуточного меню настроек нет.
- Пользователей пока нет; обратная совместимость не требуется. Дополнительные маршруты `/more/settings`, `/more/data`, `/more/offline` удалены без переходных редиректов. Текущие внутренние ссылки ведут на `/more`.
- Эти правила записаны в `AGENTS.md`.

## Данные и ошибки

- **Копия:** указан состав и дата экспорта; напоминание после пяти занятий. Импорт сначала показывает новые/существующие записи и правила объединения; учитываются реальные уникальные добавления. Настройки и активная тренировка явно исключены. Снимок оставшегося плана в завершённой записи входит в копию и проверяется при чтении.
- **Импорт в браузере:** тестовый файл показал 1 новую программу и 1 занятие; повтор того же файла — 0 новых и 2 существующих. Модульные тесты проверяют повреждённые записи и восстановление плана после переноса.
- **Офлайн в production-интерфейсе:** отдельный сервер отдавал HTTP 503 для одного фото. Получено 7/8 файлов и 1 ошибка; повтор дал 8/8, 0 ошибок; статус сохранился после перезагрузки. Стенд использовал только два упражнения, чтобы не скачивать весь каталог.
- **Шаринг в production-интерфейсе:** запись в буфер запрещена настоящей `Permissions-Policy`. Ошибка видна внутри диалога, рядом с полем ручного копирования; QR и ссылка сохраняются. Отмена системного шаринга не считается ошибкой.
- **Несохранённая правка:** Escape предлагает подтверждение; отмена закрытия оставляет редактор открытым и сохраняет черновик. Проверено в браузере.

Повторяемая проверка ошибок: `npm run build`, затем `node scripts/ux-fault-server.mjs 5176`. Для чистой проверки нового билда можно выбрать другой свободный порт. Сервер слушает только loopback, ограничивает каталог двумя упражнениями, один раз возвращает 503 и запрещает clipboard-write. Это тестовый стенд, а не режим продукта.

## Визуальная и техническая проверка

- Сохранены шрифты, геометрия карточек, обе темы, focus-visible и reduced motion.
- Увеличены основные кнопки, вводы, плашки, шаговые контролы и управление карточками до области от 44 px. Размеры декоративных иконок и неинтерактивных меток не увеличивались.
- Браузер: 390 px, светлая и тёмная темы; десктоп 1280 px. Проверены список и карточки тренировки, меню и график с клавиатуры. Ширина центральной колонки сохранена; отдельный сравнительный эксперимент ширины каталога не проводился и не является обязательным изменением из аудита.
- Текст на акценте имеет не менее 4,5:1 на проверенной сетке из 4096 цветов. Измеренные пары: muted / светлая surface — 5,02:1; muted / тёмная surface — 4,79:1; success / белый — 5,02:1. Полное соответствие WCAG этим не доказано.
- Последняя полная проверка: 75 тестов в 14 файлах; каталог — 880 упражнений и 1746 исходных фото; переводы UI — 457/457; production-сборка и service worker созданы; проверка пробелов проходит. Ошибок консоли в проверенных сценариях основного приложения нет.
- Актуальные команды проверки: `npm test`, `npm run data -- --check`, `npm run i18n:check`, `npm run build`, `git diff --check`. Итоговые результаты фиксируются в коммите и сообщении о готовности.

## Незакрытая внешняя приёмка

Реализация `71256b7` опубликована на [fitnoss.app](https://fitnoss.app/). [Workflow 41135782406](https://github.com/fitnoss/fitnoss.github.io/actions/runs/41135782406) завершил build и deploy успешно. На публичном сайте проверены четыре вкладки и прямой экран «Ещё» с верхними кнопками, данными и офлайном внутри настроек. Публикация не подтверждает результаты проверок на физическом устройстве.

Чеклист и форма результата: `UX_ACCEPTANCE.md`. Пользователь сообщил, что может проверить на телефоне. Результатов этой проверки пока нет.

1. Физический телефон: клавиатура, запятая в весе, увеличение шрифта, safe-area, фон и блокировка экрана, офлайн.
2. Реальный скринридер: имена контролов, порядок фокуса, диалоги, завершение и возврат. Встроенный скринридер телефона также подходит.
3. 3–5 наблюдаемых сессий с задачами из исходного аудита. Время, неверные переходы и помощь пока не измерены; улучшение конверсии или скорости не заявляется.

Карта мышц и объём по мышцам в исходном документе обозначены следующим этапом после UX-работ, а не частью этих итераций.
